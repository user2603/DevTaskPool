# DevTaskPool

Shared registry of small automation task projects ("micro-tasks").

- Each task project lives in a folder under `tasks/` (pre-release ideas under `tasks/incubator/`).
- Teammates develop on personal branches named `dev/<their-name>`.
- The **current** review rules are in [`docs/acceptance_policy_v2.md`](docs/acceptance_policy_v2.md) (version 2, effective 2026-10-24).
- [`docs/acceptance_policy_v1.md`](docs/acceptance_policy_v1.md) is the **superseded** draft, kept for audit history only.
- [`docs/archive/review_ledger_2026-10.md`](docs/archive/review_ledger_2026-10.md) is an archived ledger of October reviews (format reference only).
